What's in it

Built like a
messaging app should be.

Everything below is in the shipped app today — not a roadmap.

✓✓

Receipts that are honest

Sent, delivered and seen are three separate states, each written the moment it actually happens.

🎙️

Voice notes

Hold the mic and talk for up to a minute. Playback shows the length before you commit to listening.

🖼️

Photos, compressed first

Images are resized in the browser before they are sent, so a full-size camera shot doesn't stall the chat.

🔍

Search inside a chat

Type a word and matches highlight in place, with the rest of the thread dimmed rather than hidden.

✏️

Edit, delete, pin

Fix a typo after sending, remove a message for everyone, or pin the one detail the group keeps asking for.

📥

Installs like an app

One tap adds it to the home screen. It opens without browser chrome and keeps working through a dead signal.

How it's built

No framework,
on purpose.

The whole app is hand-written JavaScript against the Firebase Realtime Database. Choosing no build step meant every byte on the page is something I decided to put there.

Front end
Vanilla JS · HTML · CSS
Data
Firebase Realtime DB 8.10

AK Ayush Kumar Founder & sole developer

I built TINDER Message because group chats kept turning into feeds. I wanted something small and quiet that only the people I know can get into — so I wrote it end to end: the interface, the data model, the receipts, the service worker.

It is a real app used by real people, not a demo. Every feature on this page shipped because someone in the group asked for it.

Get it on your phone

Install in one tap.

No app store, no download queue, no 60 MB. The button adds TINDER Message straight to your home screen.

01 · INSTALL

Tap the button. Your browser confirms, and the icon lands on your home screen.

02 · SIGN IN

Pick a username and set a password. That password gets you in from any device.

03 · START TALKING

You land in the group chat. Private conversations are one tap from the list.
